# Publication and citation guidance

This repository is designed as a general public research resource for AR-CBT++.

## Suggested code-availability wording

> Code availability. Public analysis code, figure-generation scripts, the retained three-judge execution notebook, exact open-weight model revisions, and integrity-audit artifacts are available in the versioned AR-CBT++ public reproducibility repository. The repository excludes the private unblinding key and unnecessary safety-sensitive raw dialogue text. The complete historical judge-specific decoding configuration remains incompletely documented, as described in the reproducibility limitations.

## Suggested data-availability wording

> Data availability. Public analysis-ready numerical/categorical tables and derived result tables are available in the versioned AR-CBT++ reproducibility repository. The private unblinding key and unnecessary safety-sensitive raw dialogue text are excluded from the public release. Additional retained research materials may be available subject to applicable model-license and safety-content restrictions.

## Citation

Use the repository's `CITATION.cff` file for the preferred citation metadata.
